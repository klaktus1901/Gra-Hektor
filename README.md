# Gra Hektor

## Mechaniki
### Aparat jako źródło nawigacji
- Aparatem robisz zdjęcia wraz z flashem, możesz podejrzeć zdjęcie przez chwilę aby zapamiętać layout któremu zdjęcie zrobiłeś.
- Jeżeli Hektor goni gracza, można robić zdjęcia bez podglądu, tylko flash.
- Tryb aparatu będzie kontrolować gracz, nie gra.
- Sama gra ma bardzo małą ilość świateł, przez co aparat stanie się niezbędny.

### Ślepy antagonista
- Hektor jest ślepy, ale słyszy.
- Hektor zawsze idzie do ostatniego, usłyszanego źródła nieznanego dźwięku.
- Gra podświadomie podsyła przybliżoną pozycję Hektora, aby gracz nie mógł go unikać.

### Cel gry
- Gracz ma znaleźć przyjaciela i z nim uciec.

### Obiekty z otoczenia ułatwiające rozgrywkę
- Radio, gracz może je włączyć i odciągnąć Hektora od siebie. Gracz może je przenieść.

## Historia
### Hektor
- Hektor to lokalna miejska legenda, matki go wykorzystują aby straszyć nim dzieci "jak nie zjesz obiadu to Hektor po ciebie przyjdzie".
- Hektor to ślepy starzec, weteran z czasów wojny, jego instynkty żołnierza wracają.

### Dwóch głównych kolegów
- Dwóch kolegów idzie sprawdzić czy legenda jest prawdziwa, zakradają się do jego domu, a Hektor, źle interpretując sytuację myśli że ktoś się włamał do domu i zabiera kolegę do piwnicy.

## Mapa
- Mapa obejmuje dom, który jest nie wielki, oraz 3 poziomy piwnicy, które są bardziej obszerne.
- Na każdym niższym piętrze piwnicy, graczowi są ukazywane wspomnienia Hektora z wojny (najprawdopodobniej jako grywalna część gry), a po tym wraca do teraźniejszości.
